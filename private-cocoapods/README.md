# Private CocoaPods lockfile inventory

`RehearsalPolicy` is a real local development pod with an AFNetworking dependency.
The committed lockfile and checksums were generated by CocoaPods 1.16.2 with
`pod install`. The Podfile disables Xcode project integration so dependency
installation also works on Linux; compiling the Objective-C example requires an
Apple SDK and an application target containing `main.m`.

Run `pod install` in this directory to regenerate the lockfile. The package source
is in `registry-fixtures/packages/cocoapods`. To qualify a private spec repository,
publish that podspec and source under the rehearsal account, replace the local
`:path` declaration with the private spec source, and regenerate the lockfile in
a clean client cache. Do not commit private Git credentials.

ZeroPath currently reads `Podfile.lock`; it does not run CocoaPods to generate a
missing lockfile. This local fixture tests recorded internal inventory and edges,
not remote registry authentication. VCS-backed private specs use the existing
repository authentication path. A local/private source cannot prove that a
same-named public package was remediated.
